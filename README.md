# El Pollo Loco

A 2D browser game built with JavaScript where the player fights enemies, collects coins and bottles, and defeats the final boss.

## Live Demo

https://hld2705.github.io/El-Pollo-Loco/


## Features

- Object-oriented JavaScript gameplay
- Character movement and animations
- Collision detection
- Boss fight mechanics
- Sound effects and game UI
- Responsive design

- JavaScript
